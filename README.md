# Cảm nhận sách: AI và Con Người

Website tĩnh giới thiệu cảm nhận về cuốn *AI và Con Người* của GS. Hồ Tú Bảo. Trang được xây dựng bằng HTML, CSS và JavaScript thuần, không cần cài đặt thư viện.

## Xem trang trên máy

Mở `index.html` bằng trình duyệt. Website dùng Google Fonts để hiển thị kiểu chữ; nếu không có kết nối mạng, trang sẽ tự dùng font dự phòng.

## Đưa website lên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Tải các tệp trong thư mục này lên repository và commit chúng.
3. Mở **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/(root)`, rồi bấm **Save**.
5. Sau khi GitHub Pages hoàn tất, mở đường dẫn được hiển thị trong phần Pages.

Trang chủ đã đặt tên `index.html` để GitHub Pages tự nhận diện.
